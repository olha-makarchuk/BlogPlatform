# BlogPlatform

## Опис
Todo List — це повнофункціональний веб-застосунок для керування списком завдань, створений на **React**. Додаток дозволяє додавати нові завдання, відмічати їх як виконані, видаляти, фільтрувати та переглядати статистику виконання.

## Функціональні можливості

### Публічні сторінки

- Головна (/) — список останніх статей з фільтрами та пагінацією

- Сторінка статті (/posts/:id) — деталі статті, автор, категорія, теги, коментарі, рекомендовані статті

- Сторінка автора (/authors/:id) — базова інформація + вкладені розділи "Статті" / "Про автора"

- Категорії (/categories) — список категорій

- Сторінка категорії (/categories/:slug) — статті певної категорії, пошук та сортування

- Пошук (/search) — пошук по заголовках, тексту статей, авторам, категоріям

- Про нас (/about)

- 404 — сторінка "Сторінка не знайдена"

### Захищені сторінки (тільки для авторизованих)

- Створення статті (/posts/new)

- Редагування статті (/posts/:id/edit)

- Dashboard (/dashboard) з вкладеними сторінками:

- /dashboard — статистика, графіки

- /dashboard/my-posts — список власних статей

- /dashboard/settings — налаштування профілю

### Навігація

- Header: логотип, меню (Головна | Категорії | Автори | Про нас), пошук, кнопка "Увійти"/аватар користувача

- Мобільна навігація: бургер-меню < 768px

- Breadcrumbs: поточний шлях (клікабельний, окрім останнього елемента)

- Кнопка "Назад" для деяких сторінок

### Фільтри та сортування

- Фільтри по категоріях та авторам

- Сортування: за датою, переглядами, назвою

- Пагінація через URL параметри (?page=2&q=...&sort=...)

- Коментарі та взаємодія

- Список коментарів з вкладеними відповідями

- Додавання коментарів (тільки для авторизованих)

- Кнопка "Редагувати" для автора статті

### Авторизація (mock)

- Login/Logout, редірект після входу

- Збереження стану авторизації через Context та localStorage

- Доступ до захищених сторінок тільки для авторизованих

### Оптимізація

- React.lazy та Suspense для code splitting

- Scroll to top при зміні сторінки

- Loading states та skeleton/spinner

## Запуск проєкту
1. Клонувати репозиторій:
```bash
git clone https://github.com/olha-makarchuk/BlogPlatform.git
```

2. Встановити залежності:
```bash
npm install
```

3. Запустити локально:
```bash
npm ren dev
```
